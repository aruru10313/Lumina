개인정보처리방침

시행일: 2026년 11월 15일

Lumina 프로젝트(이하 "프로젝트")는 이 웹사이트(lumina.aruru.kr)를 운영하면서 이용자의 개인정보를 직접 수집하거나 저장하지 않습니다. 회원가입, 로그인, 문의 양식, 광고, 방문자 분석 도구(Google Analytics 등)를 쓰지 않습니다.

1. 수집하는 개인정보

프로젝트는 이용자의 개인정보를 수집하지 않습니다. 따라서 개인정보의 보유·이용 기간, 제3자 제공, 처리 위탁에 해당하는 사항이 없습니다.

2. 쿠키와 브라우저 저장소

쿠키를 쓰지 않습니다. 고른 언어(한국어/영어)를 기억하기 위해 브라우저의 localStorage에 lumina.lang 값 하나만 저장합니다. 이 값은 이용자의 기기에만 남고 어디로도 보내지지 않으며, 브라우저 설정에서 언제든 지울 수 있습니다.

3. 외부 서비스

사이트와 파일 제공을 위해 아래 외부 서비스를 씁니다. 이 서비스들은 접속할 때 IP 주소, 브라우저 정보, 접속 시각 같은 기술 정보를 자체 정책에 따라 처리할 수 있습니다.

4. 서버 프로그램(Lumina jar)

Lumina 서버 프로그램은 프로젝트에 어떤 정보도 보내지 않습니다. 처음 실행할 때 Mojang 서버 파일을 Mojang에서 받으며, 이 과정은 Mojang·Microsoft의 정책을 따릅니다. 원본 Paper/Folia에 들어 있는 bStats 통계 기능은 서버 운영자가 plugins/bStats/config.yml에서 끌 수 있습니다.

5. 이용자의 권리와 문의

프로젝트는 개인정보를 갖고 있지 않으므로 열람·정정·삭제를 요청할 정보가 없습니다. 궁금한 점은 GitHub 이슈로 남겨 주세요. 이슈는 공개 게시판이니 개인정보를 적지 마세요.

6. 변경

이 방침이 바뀌면 이 페이지에 새 시행일과 함께 게시합니다. 변경 기록은 GitHub에서 볼 수 있습니다.

Privacy Policy

Effective: November 15, 2026

The Lumina project ("we") does not collect or store personal data through this website (lumina.aruru.kr). There are no accounts, logins, contact forms, ads or analytics tools (such as Google Analytics).

1. Data we collect

None. There is therefore nothing to retain, share with third parties or outsource.

2. Cookies and browser storage

No cookies are used. A single value, lumina.lang, is stored in your browser's localStorage to remember your language. It stays on your device, is never sent anywhere, and can be cleared from your browser settings at any time.

3. Third-party services

The services below host the site and files. They may process technical data such as IP address, browser information and access time under their own policies.

4. The server software (Lumina jar)

The Lumina server sends no data to us. On first start it downloads the Mojang server from Mojang, subject to Mojang/Microsoft policies. The bStats metrics inherited from Paper/Folia can be disabled by the server operator in plugins/bStats/config.yml.

5. Your rights and contact

We hold no personal data, so there is nothing to access, correct or delete. Questions: open a GitHub issue. Issues are public, so please don't include personal information.

6. Changes

Changes are posted here with a new effective date. History: GitHub.
