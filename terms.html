이용 안내 및 면책

시행일: 2026년 11월 15일

1. PaperMC에서 지원하지 않는 비공식 프로젝트

Lumina는 Folia와 Paper를 기반으로 한 비공식 포크입니다. PaperMC 팀과 관련이 없으며, PaperMC는 Lumina를 만들거나 검증하거나 지원하지 않습니다. Lumina에서 생긴 문제를 Paper·Folia 저장소나 PaperMC 디스코드에 신고하지 마시고 Lumina 저장소에 알려 주세요.

Minecraft는 Mojang Studios의 상표입니다. Lumina와 이 사이트는 Mojang·Microsoft와 관련이 없습니다. Lumina로 서버를 열려면 Minecraft EULA에 동의해야 합니다.

2. 라이선스

Lumina의 소스와 패치는 원본 프로젝트의 라이선스(GPLv3 등)를 따릅니다. 자세한 내용은 저장소의 LICENSE와 PATCHES-LICENSE를 보세요. Lumina jar에는 Mojang 서버 코드가 들어 있지 않으며, 실행할 때 Mojang에서 직접 받습니다.

3. 보증 없음

Lumina는 있는 그대로(AS IS) 제공되며 어떤 보증도 하지 않습니다. 일반 플러그인 호환 모드는 실험적인 기능입니다. 월드 손상, 데이터 유실, 서버 멈춤, 성능 저하 등에 대해 프로젝트는 책임지지 않습니다. 운영 서버에 쓰기 전에 반드시 백업하고 테스트 서버에서 확인하세요.

4. 공식 배포처

공식 배포처는 이 사이트(lumina.aruru.kr)와 GitHub Releases뿐입니다. 다른 곳에서 받은 파일은 변조되었을 수 있습니다. 받은 파일은 다운로드 페이지에 표시된 SHA-256 값과 비교해서 확인하세요.

5. 문의

GitHub 이슈로 남겨 주세요.
